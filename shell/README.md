# rig-shell

The Rig board pane for the ADE shell. It is a Go program (Bubble Tea) that reads
everything through the local API (`docs/local-api.md`) and never opens `.rig`
files. Labels, tones, glyphs, ordering and counts come from the server
(`scripts/board_view.py`), so this program only renders.

```sh
cd shell
go build -o bin/rig-shell ./cmd/rig-shell   # needs Go 1.24+
go test ./...                               # offline once modules are cached

bin/rig-shell --repo /path/to/repo          # interactive
bin/rig-shell --once --size 120x36          # one frame to stdout
bin/rig-shell --once --fixture testdata/snapshot.json --tab Queue
```

If no API server answers, it runs `rig api ensure` (override with `--rig` or
`RIG_BIN`, disable with `--no-ensure`). The server exits after 60 idle seconds.

Keys: `Tab` next pane, `j`/`k` move, `Enter` details, `a`/`d` allow or deny an
ASK, `x` stop (asks first), `e` enqueue, `r` refresh, `q` quit. `RIG_TUI_ASCII=1`,
`RIG_TUI_CJK=1` or a non-UTF locale selects ASCII glyphs.

## Fixtures and goldens

`testdata/snapshot.json` is generated by the Python view builder from
`testdata/sample-board.json`; `tests/test_board_view.py` fails when it drifts.
Refresh it with `RIG_UPDATE_FIXTURES=1 python3 tests/test_board_view.py GoShellFixture`.
Golden frames live in `testdata/golden/`; refresh with `go test ./... -update`.
